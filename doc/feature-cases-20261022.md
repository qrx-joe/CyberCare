# 功能案例与测试对照（2026-10-22）

目的：给当前本地原型的**每一个功能**配一对可核对的交付物——一个**案例**（谁、在什么场景下做什么、期望看到什么）和对应的**自动化测试**（业务测试 `npm.cmd test` / 浏览器 e2e `npm.cmd run test:e2e` 中的具体用例）。本文件只做映射与验收说明，不新增承诺。

边界（与 README 一致）：

- 所有自动化测试使用合成材料或替代 Provider/SDK，**不作为**真实模型质量、真实用户效果、WCAG 符合性或公益采用的证据。
- 每个功能末尾列出"仅手工 / 未验证"项：这些是自动化测试覆盖不到、需要真人或真实配置才能验收的部分。
- 检测、确认与导出闭环里，"axe 检测通过 + 人工确认"只代表本次导出的那份 HTML 通过了自动规则检查，不代表认证。

测试文件索引：业务测试在 `tests/*.test.mjs`，浏览器测试在 `tests/browser/*.spec.mjs`。下文用 `文件名「测试名」` 定位。

## F1 海报任务闭环（内置合成样例）

**案例 F1-C1（首次使用者，零模型配置）**：新会话打开首页，材料来源选"内置合成样例"，勾选材料声明，生成草稿；核对四项信息，修正一处地点；点检测（axe 实际运行）；逐项确认四字段与全文；下载文字、大字 HTML、证据 JSON；提交反馈；删除任务。期望：全程不发起外部模型请求，导出内容与界面核对内容一致，删除后任务不可再访问。

**案例 F1-C2（键盘与放大）**：全程只用键盘（Tab / 回车）完成 F1-C1，并在 200% 字号、320px 窄屏下重复关键步骤。期望：无需鼠标即可完成，页面重排后仍可读可用。

自动化：

- domain.test「无模型配置不以样例响应任意图片；手工路径请求数为零」
- browser/demo.spec「合成样例离线闭环：修正→实际 axe→逐项确认→导出→反馈→删除」
- browser/demo.spec「主要流程只用键盘完成；200% 文字与 320px 重排」
- browser/provider-config.spec「真实识别配置无效时说明问题，合成任务仍能继续，不创建模型请求」

仅手工 / 未验证：真实读屏软件（NVDA 等）下的操作体验；首次使用的公益志愿者能否独立走完。

## F2 人工转录路径

**案例 F2-C1**：用户拿到海报文字（如从活动方微信群复制），选"人工转录"粘贴，声明来源，生成草稿。期望：只按"活动名称："等明确标签解析；标签缺失的字段保持未知，不以常识补全；导出标注"人工转录，非 AI 识别"。

**案例 F2-C2（恶意输入）**：粘贴含 HTML/脚本字符的文字并进入导出。期望：输出按纯文本转义，不执行、不渲染注入内容。

自动化：

- domain.test「缺失报名方式保持未知；不以常识补全」
- domain.test「无转录依据的模型字段归为未知」
- browser/demo.spec「人工转录、键盘、恶意文字、导出门禁、来源校验、响应式与页面 axe」

仅手工 / 未验证：真实转录者的录入耗时与错误率。

## F3 真实识别路径（StepFun，可选）

**案例 F3-C1（配置且获准时）**：`.env` 配置 StepFun 并设置本批请求上限，选真实识别上传海报。期望：一次任务一次请求、无自动重试；响应按四字段契约解析，引文可定位才进草稿；元数据记录等待上限、推理强度与 token 用量（不可得写未知）。

**案例 F3-C2（失败转人工）**：模型超时 / 截断（`finish_reason=length`）/ 鉴权失败。期望：不生成不完整草稿；本页图片与来源保留，可转人工核对并完成实际导出；HTTP 402 明确提示核对 API 额度并停止，不用重试规避。

**案例 F3-C3（未配置）**：无密钥时选择真实识别。期望：入口明确说明不可用与原因，不显示伪造结果；样例与人工路径不受影响。

自动化：

- provider.test 全部 9 条（有界等待与推理强度、配置错误前置拒绝、`finish_reason=length` 拒绝、取消、套餐地址不回落、HTTP 失败不泄露不重试、截断单列、402 停止、错误分类）
- domain.test「模拟上游验证请求硬上限、无自动重试、鉴权失败停止；不作真实模型质量证据」
- browser/demo.spec「真实图片上传与解码；伪装、超像素图片被拒绝；不会进入假识别」「创建响应丢失后，同材料重试复用原任务」
- browser/fallback.spec「模型失败后保留本页图片和来源，转人工核对并完成实际导出」「已取消识别可转人工，保留材料不延长原期限，到期仍清空图片与文字」「转人工期间资料到期，晚到的删除响应不能恢复图片或来源」
- browser/provider-config.spec「真实识别配置无效时说明问题，合成任务仍能继续，不创建模型请求」「识别前与等待中展示实际 30 / 90 秒上限，兼容旧配置，无真实模型调用」（同一条用例在两个超时配置下各跑一次）
- browser/assistance-upload.spec「真实上传链路的替代 Provider 回归：浏览器转换音频、服务端解码截图与补图继续」

仅手工 / 未验证：真实中文海报整体准确率（历史记录含超时、截断、遗漏、字段语义错误，见 `doc/readme-history-20261022.md`）；真实语音由真实模型转写的误识别（见 `doc/multimodal-20261022.md`）。

## F4 图片上传校验

**案例 F4-C1**：分别上传正常 PNG、伪装扩展名的文本、超 2MB、超 8000 边长 / 1600 万像素的图片。期望：服务端逐一拒绝并给出具体错误码（`FILE_INVALID` / `FILE_TOO_LARGE` / `IMAGE_DIMENSIONS`），伪装文件不会进入任何识别流程；浏览器端更换无效文件时清除旧查看状态。

自动化：

- domain.test「文件签名和大小受服务端约束」
- browser/demo.spec「真实图片上传与解码；伪装、超像素图片被拒绝；不会进入假识别」
- browser/source-image-review.spec「替换、无效文件及加载失败清除旧查看状态，临近到期放大不延长图片留存」

仅手工 / 未验证：无（服务端规则已全覆盖）。

## F5 四项字段核对与未知语义

**案例 F5-C1（多行字段）**：海报时间含两行（日期 + 截止），地点换行。期望：核对页多行完整显示，无需内部滚动即可读全；修改其他字段不拼接、不丢换行；导出保持原样。

**案例 F5-C2（四项全未知）**：模型四项都提取失败。期望：四项显示"未知，请向活动方核实"，可回到材料对照；输入提示随草稿更新；仍可明确确认"未知"并走完检测与导出，导出保留未知与提醒。

## F6 证据定位与原文摘录

- browser/quote-excerpt.spec「可定位片段由人显式填入草稿，不自动保存或覆盖，修改使检测确认失效」「摘录仅含当前正文可定位且长度合规的文字，防止脚本、覆盖、正文变化与到期后使用」

仅手工 / 未验证：无。

## F7 时间提醒（年份 / 相对日期 / 分散条目）

**案例 F7-C1（缺年份）**：海报时间只写"10 月 24 日 14:00"。期望：核对页与实际导出的文字 / HTML 都带"年份待核实"提醒；不自动补全年份，不从另一条截止时间借年份；补充年份保存后提醒消失且旧检测失效。

**案例 F7-C2（相对日期）**：时间写"本周六下午"。期望：即使另含年份也提醒相对表述待核实；原文保留，不按阅读当天换算。

**案例 F7-C3（分散时间条目）**：正文里活动日期与报名截止分散两处。期望：须由人选择并分类（活动日期 / 报名截止 / 提交截止）后写入；用途待核实的条目不自动升级；保存重测后正文与下载区分活动日期及截止；一条有年份不能掩盖另一条缺年份。

自动化：

- domain.test「导出提醒接收者核实缺少年份的日期；核实补充后移除提醒并失效旧检测」「相对日期即使包含年份也须提醒，原文保留且不按阅读日期换算」
- time-references.test 全部 5 条
- browser/content.spec「含年份的相对日期仍在核对页和实际导出中提醒，保留材料原文」「缺年份提醒进入实际文字和 HTML 下载；检测哈希仍对应同一份文件」
- browser/time-references.spec「分散时间须选择与分类后写入；保存重测后正文与下载区分活动日期及截止」「用途待核实、正文变化、既有值、500字限制和到期均不触发自动改写」

仅手工 / 未验证：提醒措辞是否真的让接收者去核实（需用户观察）。

## F11 无障碍检测（axe）门禁

**案例 F11-C1**：未检测先确认 / 检测后修改草稿再确认。期望：`AUDIT_REQUIRED` / 修订使旧报告失效，必须对当前版本重新检测；检测的是本次导出的同版本 HTML（哈希绑定），人工改动使哈希失配。

**案例 F11-C2**：检测发现 serious / critical 问题。期望：确认被阻断（`AUDIT_BLOCKED`），修复后重测才能确认；axe 运行失败不得记为零问题（未覆盖项如实列出）。

- domain.test「确认要求当前检测；人工改动使旧报告失效；输出转义 HTML」
- browser/demo.spec「合成样例离线闭环：修正→实际 axe→逐项确认→导出→反馈→删除」（真实 axe 运行）
- browser/story.spec「缺素材时停用动作并准确说明文字退路；减少动态与科普展开后整页 axe」
- browser/workspace.spec「三个页面与登录弹窗在窄屏、大字下无横向溢出，axe 保留未覆盖项」

## F13 任务生命周期、幂等与会话

**案例 F13-C1（30 分钟到期）**：任务创建后放置 30 分钟。期望：到期即不可访问（404 `TASK_NOT_FOUND`），页面同步清空文字、文件与 Blob 引用；晚到的检测 / 删除响应不能复活任务；未提交的人工草稿同样到期，切换模式不能恢复过期输入。

**案例 F13-C2（幂等与冲突）**：同一请求编号重复提交同材料。期望：复用原任务不重复处理；同编号换材料报 `IDEMPOTENCY_CONFLICT`；跨会话访问 404；删除撤回访问。

**案例 F13-C3（读取恢复）**：创建响应丢失后同材料重试。期望：复用原任务；处理中继续轮询，不重新提交、不延长到期；恢复期间到期则晚到响应作废；重读已删除任务清空页面不自动重建。

## 1. 环境与启动

```powershell
Set-Location -LiteralPath D:\code\CyberCare
npm.cmd ci
npm.cmd run typecheck
npm.cmd test
npm.cmd run test:e2e
npm.cmd start
```

打开 [http://127.0.0.1:4310](http://127.0.0.1:4310)。浏览器测试另启 4311；启动前释放该端口。默认检测器寻找本机 Chrome / Edge；找不到时在 `.env` 设置 `CHROME_PATH`，不要把检测失败当作通过。

## 2. 三分钟主流程（合成样例，无外部模型请求）

根据同日用户纠偏，开场改成“角色求注意力 → 点一次 2D 示意互动 → 展开一条短科普 → 点击做件小事”，建议控制在 30 秒以内，再进入下表核对流程。角色台词和科普明确是固定示例，不能在台上称为实时 AI 对话。完成后展示“这次咱俩都站着”与真实核对回执。完整取舍见 [方向纠偏](direction-reset-20261016.md)。

| 时间 | 操作 | 应看见的事实 |
|---|---|---|
| 0:00–0:25 | 说明“这是技术演示，合成素材，未调用视觉模型”；选择内置合成样例 | 海报与转录均写明非真实活动；没有伪造真实受益者或成绩 |
| 0:25–0:50 | 勾选材料声明，生成草稿 | 处理路径明确为标签解析、非 OCR / AI；活动名称、时间、地点有转录依据；报名方式空白且标未知 |
| 0:50–1:20 | 可修改一个字段，填写修改依据，保存 | 版本递增、证据保留修改；旧检测失效。演示修改不声称核实了真实活动 |
| 1:20–1:50 | 点击“检测当前草稿” | 服务端启动已有浏览器运行 axe；展示引擎、版本、Critical / Serious、全部问题及需人工检查数；异常时不能确认 |
| 1:50–2:20 | 对照原图与完整转录，逐项确认 4 个字段；报名方式确认保留未知；确认完整内容 | 默认不勾选；遗漏任一项或未检测当前版本时确认按钮不可用 |
| 2:20–2:45 | 确认，下载文本、HTML 和 JSON | HTML 与检测哈希对应；JSON 包含来源声明、摘要哈希、原始转录、修改、模型路径/用量、检测、确认时间及版本 |
| 2:45–3:00 | 选择可选自报反馈，再删除 | 反馈不等于独立用户验证；删除后当前任务不可读且页面资料清空 |

这一路径在依赖安装和构建完成后不需要互联网；本机服务与浏览器仍需运行。它是离线流程兜底，不能在台上宣称“AI 现场识别”。

### 提交前可选：先看结果示例

1. 在任务区用鼠标或键盘展开“先看结果示例”，无需勾选材料声明或提交材料；应看见可读文字、大字排版和记录状态。
2. 检查明确的合成 / 只读 / 未检测 / 未确认说明，预览没有正式下载按钮，也没有当前任务 ID。已输入的人工草稿、来源和处理方式应保持。
3. 点击“了解了，去提交与核对”，焦点到提交区；仍须按实际流程生成草稿、检测和逐项确认，预览不产生回执。

## 3. 输入与异常验收

- 切到人工转录：可选自己的授权海报作本地对照，粘贴包含字段标签的文本；没有标签或“未知 / 无法辨认”的字段保持未知；原文中的指令只作文字展示。无模型调用。
- 空白名称 / 时间 / 地址 / 报名字段出现具体核实提示；未写四位年份的时间提示核实日期。不会替你补年份、地址或报名渠道；填入内容后提示相应更新，修改仍使旧检测与勾选失效。
- 切换样例/手工模式前后保留相应文字草稿，不静默丢失；模型未配置时该入口不可用，不返回样例冒充结果。
- 真实识别失败或取消后，显示“保留图片，改用人工转录”。点击会删除旧任务，保留本页选图和来源，聚焦转录框并重置材料声明；本页原到期时间不变。粘贴文字后仍需生成、检测、逐项确认再导出，标注“非 OCR / AI”；不自动重试模型。模拟失败与取消的实际验证见[退路记录](manual-fallback-20261019.md)，不得为演示该分支反复发起付费请求。
- 上传不是 PNG/JPEG/WebP、超过 2 MB、超过像素限制、伪造扩展名/签名或不能实际解码的文件：服务端拒绝。上传问题不可只靠浏览器 accept 过滤。
- 未声明有权处理：不能提交。没有来源说明：不能提交。
- 未检测、存在 critical/serious 问题、未逐项确认、版本过旧：服务端拒绝确认/导出。
- 修改成功后：之前的检测和勾选失效；须重新检测、重新确认。
- 两个浏览器会话不能互读或删除对方任务；任务 ID 不是访问凭据。
- 取消处理中任务、删除或到期后：晚到响应不能重新写入。重复同幂等键和相同载荷只创建一项；不同载荷返回冲突。
- 第三方失败/超时：明确显示失败，不自动回填合成结果；删除后可切换手工路径再试。当前未开展真实模型失败演练，单元测试使用替代请求验证。
- 删除任务后访问原任务 API 返回 404；30 分钟期限在每次访问检查，定时清理最长再等 10 秒；堆内存实际释放时机由运行时决定。

## 4. 页面无障碍人工走查

1. 全程只用 Tab / Shift+Tab / Enter / Space：跳转到主区，选择、上传、核对、检测、确认、导出、反馈、删除；焦点可见且无陷阱。
2. 切大字模式，检查转录、字段、错误、检测报告和最终文字实际放大。320px 宽度及文字 200% 下检查重排，不能只看页面没有横向滚动。
3. 用至少一种桌面读屏和一种移动读屏从头走同一任务，核查状态提示、标题顺序、字段关联、未知项、错误、下载与删除。记录设备、浏览器和读屏版本。
4. 自动 axe 与人工项目分别记录；`incomplete` 项必须查看原因，不能写成自动通过。

本轮浏览器自动化不等于完整人工键盘或真人读屏评估。结果见 [验证记录](validation-20261016.md)。

## 5. 真实模型与产品价值另行验收

取得一张有权处理且无个人信息的真实海报，准备人工答案与未知项。在本地配置视觉模型后，先声明 1–3 次请求上限（含失败和重试，本适配器重试为 0），最多 30 秒/次；遇鉴权/额度失败、严重事实虚构或敏感信息立即停止，连续两次其他失败停止。

逐字段记录原图事实、AI 值、未知处理、人工修正、耗时、请求数和可得 Token；没有 usage 则为未知，不编造费用。官方接口格式参考不代表识别质量已验证。

接收者验证需单列同意、真实任务、是否找对时间/地点/报名方式、额外帮助、误解及耗时。机构采用需要实际需求方证据。研究中的“≥10 张”“≥5 人”“≤3 分钟”和 PRD 的正确率目标均不得从合成样例测试外推。

## 6. 交付门槛

- 本地技术 Demo：类型、构建、业务测试、浏览器主流程通过；样例和未验证能力可见。
- 真实 AI 演示：另有真实模型样本记录，不得把仅配好环境变量称为跑通。
- 赛事版本：另核实官方日程、工具要求，补授权材料与接收者验证；没有证据的指标继续标未验证。
- 公网版本：另评估 HTTPS、持久存储、多实例预算/幂等、鉴权、隐私留存和供应商条款；获得部署授权再执行。

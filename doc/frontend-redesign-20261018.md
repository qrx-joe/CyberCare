# 前端视觉重排：2026-10-18

依据：用户指出当前前端“AI 感太强，毫无设计感”。本轮将既有页面直接重排为公益小报 / 活动海报的视觉方向；这是可回滚的本地设计迭代，审美是否符合用户预期仍待评审。

## 实际改变

- 纸色背景、深墨色文字与朱红主操作，移除霓虹渐变、发光和重复圆角卡片。
- 标题改用系统宋体字族与明确断行；通过字号、留白、分栏和细线建立阅读层次。没有加载在线字体或增加依赖。
- 首页主任务入口提前，预设互动为次级操作。原有开场、2D 动画、科普和跳过入口继续可用。
- 角色使用原有本地帧图，展示区采用平面底色，移除装饰光环；素材说明收进可展开详情。没有生成或改写角色素材，其对外授权仍待核实。
- 任务区采用连续版面与列间分隔，合成预览、编辑、检测、确认、复制和下载的实际流程保持原样。

## 修改范围与结构影响

- `src/web/index.html`：标题、导航、任务标题与版面标识；主入口的顺序；角色说明的组织。
- `src/web/style.css`：整页视觉样式和响应式规则。
- 页面行为模块 `app.ts` / `host.ts`、契约、Provider、会话服务、领域规则及导出模板均未修改。旧内容确认、版本失效、导出 HTML 与检测 hash 的关系继续由原实现负责。
- 没有实施上一份参考方案中的分步工作台、正式阅读预览或新接口。此次实现只处理视觉反馈，不将它们记为已完成。

## 验证

- `npm.cmd run build` 与 `npm.cmd run typecheck` 通过。
- `npm.cmd run test:e2e`：18 项通过，46 秒；包括键盘闭环、1440 / 390 / 320px 重排、320px 下 200% 文字、页面 axe、编辑失效旧检测、确认导出、剪贴板拒绝退路、删除与到期、角色帧变化/暂停/减少动态、缺素材退路。
- 在本地浏览器实际查看首页和任务区，检查主入口、标题断行、角色与任务版面。没有用自动测试证明审美、读屏实际可用性、转化或社会效果。
- 本轮 StepFun 推理请求 0 次；浏览器测试服务器的模型调用上限为 0。构建没有重启已有 4310 / 4312 服务。

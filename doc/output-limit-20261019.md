## 修复与验证

新增回归证明：旧代码遇到 `finish_reason=length`，如果正文碰巧是合法 JSON，仍会接受为草稿，出现 `Missing expected rejection`。这不是本次真实响应的形态，而是需要防止的另一个截断分支。

- 现在将 `length` 统一列为 `output-truncated`，在解析和形成草稿前拒绝；向操作者说明结果不完整，可以保留材料转人工，不自动重试。
- 增加 `MODEL_MAX_TOKENS`：默认仍为 2500，显式值须为 256–8192 的整数。越界只禁用真实路径，合成与人工路径可继续；不会自动提高预算。
- 请求、成功元数据、失败诊断记录实际输出上限，旧记录不补填。只保留允许的用量计数，不保存上游正文或任意错误；非截断的 JSON 错误仍有独立分类。

`npm.cmd test`：strict 构建及 **29/29** 通过。`npm.cmd run test:e2e -- tests/browser/fallback.spec.mjs`：**3/3 定向通过**，覆盖截断错误说明后转人工实际生成、axe、逐项确认与文本下载，以及原期限和迟到响应保护。状态与上游是明确的测试替代，后续人工操作走真实本地服务，测试请求模型 0 次。最近全量浏览器 27 项仍按[上一节点](model-wait-20261019.md)的版本与范围记录，本节点未重跑全量。

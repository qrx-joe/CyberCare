## 六段产品方案

| 段落 | 核心表达 | 可展示证据 / 仍缺证据 |
|---|---|---|
| 1 问题 | 公益信息做成图片后，如何让需要文字的人获得活动时间、地点和报名方式？ | 用明确标注的合成海报解释场景；当前没有真实受益人故事 |
| 2 入口 | “给我一点注意力，一起做一件小事。”角色可跳过，科普能查来源 | 实际角色/文字退路与科普；有趣程度与动机提升未验证 |
| 3 行动 | AI 或人工转录起草，操作者修正四字段与全文，未知明确留下 | 运行中的修正、修改依据与版本；合成/手工/live 标签始终可见 |
| 4 可信交付 | 自动检测绑定导出版本，逐项确认后带走文字、HTML、证据 JSON | 实际 axe 与 HTML hash；不是事实认证或完整 WCAG 符合性 |
| 5 价值检验 | 比较现有做法，观察接收者能否用对事实、少依赖额外帮助 | 已有评估工具与空白协议；真实效果与采用未开展 |
| 6 下一步 | 先真实材料与用户验证，再可靠发布/撤回和底座接入 | [底座准备](deployment-20261017.md)及未决项；没有宣称上线或获奖 |

## 三分钟本地演练

1. 0:00–0:25：展示入口与一次互动，然后跳到任务。讲述“这是预设角色，材料是开发者合成案例”，不要扮演真实受助者或真人服务。
2. 0:25–0:45：打开结果示例，展示可读文字与大字排版；说明预览未检测、未确认，也不会发模型请求。
3. 0:45–1:25：生成合成草稿；展示缺报名方式仍未知；展开全文编辑，修正一处合成说明并填依据，保存后检测失效。不要补一个虚构报名渠道。
4. 1:25–2:10：实际运行 axe，逐项核对和确认，下载 HTML 与证据记录。指出“检测与最终 HTML 是同一版；这还不证明原图事实或真实用户体验”。
5. 2:10–2:35：打开下载的文字/HTML，说明接收者不需要再上传原图即可阅读文件。当前没有公开分享链接，文件仍需用户自行选择接收与分享方式。
6. 2:35–3:00：展示评估报告的来源与边界，保留缺口；删除演练任务，说明下载文件不会随任务删除。

以上是计划时段，未声称真人三分钟完成。演练前在目标设备计时；超过时先减少讲述，不跳过核对与检测。

## 四分钟讲述与一分钟问答准备

| 时间 | 配合页面 | 讲述要点 |
|---|---|---|
| 0:00–0:35 | 第 1 页 | 说明海报信息获取场景与首批用户假设，不编造受益人故事 |
| 0:35–1:05 | 第 2 页 | 角色争取注意力、科普说明原因；可跳过，趣味效果待验证 |
| 1:05–2:35 | 第 3–4 页与实际 Demo | 使用合成材料演示未知、修正、同版本检测和确认导出；提前备好与现场版本一致的演示结果，不冒充实时模型调用 |
| 2:35–3:15 | 第 5 页及原始评估记录 | 说明中文同图匹配与竞赛图失败；时间候选匹配不等于整例通过，不把人工演示或自动化检查包装成模型 / 用户效果 |
| 3:15–4:00 | 第 6 页 | 说明真实材料、参与者、采用与可靠发布路径，以及当前缺口 |

这是待真人计时的安排，未声称已经四分钟讲完；实际操作超时则减少讲述或使用明确标记的同版本预录素材，不绕过核对和检测。

一分钟问答按评委实际问题回答，不预设能讲完全部问题：

| 可能问题 | 当前可以据实回答的内容 |
|---|---|
| 与现有 OCR 有什么差别？ | 当前增量是关键字段、未知、全文修订留痕和同版本检测确认；是否更省力还需对照使用验证 |
| AI 在哪里？ | 服务端 StepFun 已尝试合成材料与五张不同公开海报，另有非海报负例，保留超时、截断、差异和遗漏。当前中文 v5 同图四字段匹配；竞赛图两条时间候选匹配但概述、小字仍有问题。单例与同图回归不证明泛化，人工画面不冒充实时模型调用 |
| 怎么证明公益价值？ | 当前还没有接收者或机构采用证据；协议已准备，将看能否用对时间地点报名、额外帮助和实际采用理由 |
| 为什么需要角色？ | 它是产品的注意力入口，允许跳过；是否有帮助、是否冒犯或干扰仍需观察，不把互动数计为公益效果 |
| 自动检测通过就可靠吗？ | 只覆盖自动无障碍规则；事实、读屏体验与语义一致性仍需核对，修改会失效旧检测 |
| 如何让别人用？ | 当前支持确认后下载文字和 HTML；公开阅读、发布归属与撤回尚未形成完整线上闭环 |

## 现场退路与措辞

- 无模型/无网络：用合成样例跑本地闭环；明确“非 AI”，不说实时识别已成功。
- 无角色图片：用文字角色继续；未核实对外许可的图像不装入公开材料。
- 检测失败：保留失败，不显示零问题；检查本机浏览器后重测，不绕过门禁。
- 剪贴板拒绝：选中现有结果，键盘复制或下载纯文本；不需要重新生成。
- 不说“已帮助多少人”“达到 95% 准确率”“符合全部 WCAG”“具备获奖水平”。可以说“本地流程与合成回归已完成，准备验证实际使用价值”。

若参赛，先重新取得官方规则与要求、确认素材与材料可公开范围，再生成最终展示文件和提交。现在的竞争力应来自能解释的产品取舍、可复跑闭环与如实呈现失败，而不是拟制成绩。

# 源码交付后的本地启动

本指南面向本地技术演示。源码 ZIP 不是安装程序；第一次还原依赖需要可用 npm 缓存或软件源。完成安装后，合成样例与人工转录流程不需要外部模型或互联网，本机服务与已有浏览器仍须运行。

## 首次启动

需要 Node.js 24+、npm，以及已安装的 Chrome 或 Edge。解压到一个新目录，在该目录打开 PowerShell：

```powershell
npm.cmd ci
$env:MODEL_REQUEST_LIMIT = '0'
npm.cmd run dev
```

打开终端输出的本地地址，默认 `http://127.0.0.1:4310`。先选择“内置合成样例”，声明材料使用依据后生成、核对、检测、逐项确认，再下载文字、HTML 和回执。样例明确不是 AI 识别或真实活动。

若端口占用，先停止自己刚启动的服务，设置 `$env:PORT = '4316'` 等空闲端口再启动；不要结束其他未知服务。若未找到浏览器，在自己的本地 `.env` 配置已有浏览器的 `CHROME_PATH` 后重启，不安装或下载新的浏览器来掩盖缺失。

源码不含角色参考图和派生帧，默认显示文字角色；预设互动、固定科普与海报任务仍可运行。有权使用的角色素材可按 [README](../README.md) 自行提供；不要把当前素材缺失说成动画已验证。

## 人工转录与双案例

选择“人工转录”，上传有权使用的图片，粘贴四字段标签及完整文字，填写来源，再核对与导出。标签为“活动名称：”“活动时间：”“活动地点：”“报名方式：”。标签解析只读取各标签所在行，跨行日期和地点要在核对页对照原图补齐并记录依据；它不是 OCR。

字段为空可以确认保留未知。可读的报名指引与二维码目标分别核对，目标不知道就明确留下，不猜测地址。修改使旧检测失效，必须重新检测和确认当前版本。没有检测结果或检测失败时不能当成零问题。

若收到独立双案例包，先读其中的 `START-HERE.txt`。其中的模型阅读文件是此前取得的结果；`operator/` 是代理整理的人工演示输入，不能包装成现场新模型调用。PPTX、案例原图、历史模型正文和运行报告不在源码 ZIP 中，按各自独立清单交付。

## 停止、配置和限制

Ctrl+C 停止自己启动的服务。原图和任务只在进程内存，最长 30 分钟；重启会丢失，页面刷新不自动恢复任务。删除任务不能撤回已经下载的文件。不要使用真实个人或敏感资料演示。

默认先保持请求上限 0。真实识别另需接收者自己获准的 StepFun 配置，密钥只放自己的本地 `.env`，不要发送到聊天或打进源码包。有限测试应先声明请求上限及停止条件；配置存在不等于模型质量或数据策略已验证，不通过反复重启绕过测试预算。

源码包、案例包和展示文件各有冻结版本。同机干净解压通过也不能代表另一台机器、Linux、目标用户、实际采用或公网部署通过。实际交付版本及验证结果以包外清单与对应记录为准。

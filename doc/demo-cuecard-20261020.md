# 赛博公益：四分钟内部演练卡

日期：2026-10-20。配合现有六页 v6、海报 v4 与 ab2b509 源码交接。四分钟来自 10/17 读取的活动方案，本次未能重新读取最终规则；以下是内部时段分配，尚未由本人计时，也不是录好的视频。

## 0:00–0:30　问题与首批使用者

配合第 1 页。

> 如果时间、地点和报名方式都写在一张图片里，需要文字的人怎么获取这些信息？赛博公益先做一个可检查的小任务：对照原图，把内容整理成能阅读、能修订、能带走的文字。
>
> 首批操作者暂定为公益内容核对者，接收者是需要文字或大字阅读的人。这个划分仍是待验证假设。

## 0:30–1:00　角色入口

配合第 2 页，可展示一次预设互动后直接进入任务。

> 角色先借一点注意力，再用有来源的短科普解释信息障碍。用户可以跳过互动，直接做事。当前台词是预设内容，是否有趣、是否打扰，还没有真人验证。

无已确认对外许可的角色图片时，使用源码包的文字角色退路，不把缺素材包装成动画已完成。

## 1:00–2:30　实际核对与导出

配合第 3–4 页和本地 Demo。

> 这里使用开发者原创合成样例，不是现场 AI 识别。报名方式没有给出，就保留未知。原图可以放大查看，放大不会补全模糊文字。
>
> 操作者可以修订完整文字并写下依据。修改后旧检测失效，必须重新检测和逐项确认。最终带走纯文本、大字 HTML 和处理记录。

动作顺序：

1. 选择合成样例并生成草稿，指出未知报名方式。
2. 展开核对内容，点击“放大对照原图”，展示移动 / 复位。
3. 检测一次；在全文修订中给图像说明增加“开发者合成演示，不代表真实活动”，填写演示修订依据后保存，展示旧检测失效。不要把源图中的楼层改成未经核实的新楼层。
4. 重新检测，对照四字段、全文、概述和图像说明后逐项确认，包括保留未知，下载 HTML / 记录。
5. 若现场打开下载文件，说明它与被检测文件为同一版本。检测只覆盖自动规则，事实和读屏体验仍需另外验证。

若操作或检测超时，说明当前状态并改用已下载的明确版本结果，不将旧文件冒充刚生成，不跳过检测 / 确认。预留本人在目标设备演练，不把自动化测试耗时当作人工操作耗时。

## 2:30–3:15　证据与失败

配合第 5 页。**这页保留旧 v5 案例及当时技术检查，不当作最新成绩。**

> 五张不同公开海报已有尝试，包含超时、截断、遗漏与内容问题。后续提示词 v6 做了两组合成角色对照和两张旧图回归，仍有图形转录差异与微小日期无法核实，不能报告整体准确率。
>
> 当前无密钥、无角色素材的源码副本，业务 63 项、浏览器 49 项通过，另 2 项动画专项因缺帧图跳过。这些证明所覆盖的技术行为，不是用户效果。

必要时答问再展开：v6 中文回归原始 / 应用均为 3 匹配、1 图形差异，原评分未改；竞赛图两条时间候选匹配，旧四字段仍 1 匹配、2 遗漏、1 未知保留，树牌数字待核实。PPT 文件 v6 与模型提示词 v6 是不同版本维度。

## 3:15–4:00　价值检验与下一步

配合第 6 页。

> 当前完成的是本地可核对、可导出的原型。是否比人工转录和现有工具省力，是否帮助接收者用对时间、地点和报名信息，仍需要真实任务对照。
>
> 下一步记录接收者的错误、额外帮助和耗时，再看需求方是否采用，以及不采用的理由。我们暂时没有这些证据，不用处理记录或角色互动数代替社会价值。

演练结束删除本次任务，说明删除不会撤回已经下载的文件。评委代码访问、最终赛程、素材公开范围与提交动作尚未确认，不在台上称已经公开上线。

## 1. 只验证一个任务

首批直接操作者暂定为公益内容制作/核对者：将一张有权处理的公益海报转为可复制文字与大字 HTML，核对活动名称、时间、地点、报名方式，明确保留未知，再导出处理记录。这个角色划分是本轮实现假设，尚未通过访谈验证；接收者暂定为使用读屏或需要大字阅读的人。

最小闭环：

```text
提交海报与来源声明
  → 视觉模型提取 / 明确标注的人工转录兜底
  → 结构化草稿 + 转录依据 + 不确定项
  → 人工修正字段并记录修改依据
  → 服务端 axe 检测本次将导出的完整 HTML
  → 逐项确认四个关键字段及完整内容（包括确认未知）
  → 下载纯文本 / 同一份 HTML / 证据 JSON
  → 可选自报反馈、删除任务
```

最可能失败的假设：上传者确认的内容仍不足以让接收者读懂和使用。更低成本的替代方案是“人工转录 + 现有读屏/OCR”；只有实测显示本流程减少遗漏或核对负担，才有扩大 Agent 的依据。

## 3. 可运行模式与诚实降级

| 模式 | 草稿来自哪里 | 可验证范围 |
|---|---|---|
| 内置合成样例（默认） | 开发者原创海报 + 同源转录 + 标签解析 | 无模型请求；可断网跑完编辑、真实 axe、确认和导出。不是实时识别，也不是预缓存模型调用 |
| 人工转录 | 用户选图对照、粘贴转录；规则只读取明确字段标签 | 可处理自己的材料；图片不发模型，不能声称识别了图片 |
| 真实视觉识别（可选） | 服务端 StepFun `chat/completions`，多模态 `image_url` | 需要本地配置；实现适配器不等于已跑通模型或达到准确率目标 |

StepFun 适配参考其[官方多模态调用示例](https://github.com/stepfun-ai/Step-3.7-Flash#52-text-and-image-input-example)与[Chat Completions 文档](https://platform.stepfun.ai/docs/en/api-reference/chat/chat-completion-create)，没有默认猜测模型 ID。中国区 host 与国际区凭据不能混用；本 Demo 当前仅允许 `https://api.stepfun.com`。官方示例存在不代表已验证本项目中文海报质量。

真实模型：每个进程最多 10 次外部请求，可向下配置；每个任务 1 次，无自动重试；30 秒超时；鉴权、参数、额度等错误立即停用，连续两次其他失败停止。计数包含失败请求，重启会重置计数，不是账户费用上限。只使用无个人数据的授权素材；首次真实测试前说明本轮计划请求数，发现关键事实严重虚构或敏感信息时停止人工测试。回执记录可获得的 usage，未提供则为未知。

## 4. 工程取舍与结构影响

采用 Node.js 24 + TypeScript strict 的本地模块化单体，语义 HTML/CSS + 浏览器 TypeScript，不引入 React/Next.js、数据库、独立 OCR 或工作流框架。原工程规范中的 Next.js 是候选而非已有框架；本轮静态页面与有限 API 不需要它的路由/渲染能力。代价：没有框架级路由、分布式任务或持久化，升级为线上服务需要重新评估。

需求经过：页面 → HTTP → 任务用例 / 状态规则 → Provider、浏览器检测适配器 → 受控导出模板。

| 文件 | 职责 |
|---|---|
| `src/contracts.ts` | 关键字段、运行时输入/模型/确认契约；拒绝模型设置任务状态 |
| `src/domain.ts` | 依据检查、未知、版本、人工修改、确认门禁、同一导出模板 |
| `src/service.ts` | 会话归属、幂等、内存生命周期、取消/删除/过期与晚到响应保护 |
| `src/provider.ts` | StepFun 协议、超时和请求预算；手工/合成路径明确标识 |
| `src/audit.ts` | 已安装 Chrome/Edge 中实际解码图片、实际运行 axe，离线浏览器上下文 |
| `src/server.ts` | 只监听本机、请求限制、来源校验、会话 Cookie、私有下载 |
| `src/web/` | 提交、草稿对照、编辑、检测、逐项确认、反馈、导出、删除 |
| `tests/` | 业务与竞态、真实浏览器闭环；不调用外部模型 |

无数据库迁移；没有修改音频、截图或第三方系统层，因为本轮没有这些模块。新增生产依赖只用于实际边界：Zod 运行时校验（MIT）、axe-core 自动检测（MPL-2.0）、playwright-core 驱动已有浏览器（Apache-2.0）、image-size 在解码前限制像素（MIT）；版本由锁文件固定。本地原图不落盘，任务最多保留 30 分钟；删除、过期撤回 API 访问，不声称擦除 JavaScript 堆内存或第三方副本。

## 7. 10/22 页面结构与演示身份补充

10/22 后续用户授权新增语音转写与截图指导；两项已从上文的顺延范围进入实现，独立于海报检测门禁，最新范围与验证见 [多模态功能记录](multimodal-20261022.md)。下方三视图记录保留为该次页面调整的历史范围；当前另有 `/#audio` 与 `/#guide`。

根据用户提出的界面成熟度、功能集中与演示登录问题，本地界面分为三个可独立导航的视图：

| 入口 | 用途 |
|---|---|
| `/#home` | 角色互动、固定短科普、整理前后只读示例 |
| `/#workbench` | 提交、对照与修订、当前版本检测、逐项确认和导出 |
| `/#me` | 预设演示身份、本页临时任务入口、大字与关闭动作偏好、使用帮助 |

采用浏览器片段导航，同一标签页内切换不重新加载应用，保留尚未保存的核对输入；前进、后退和原有示例/任务锚点可用。刷新仍不恢复任务，未改变原有内存生命周期与检测、确认门禁。

演示登录使用两个明确标注的预设称呼，不收集手机号、密码或其他个人资料；不建立账户、身份认证、云端同步或任务历史，也不改变服务端会话归属。游客可以使用全部已有流程。演示身份仅写入当前标签页的 `sessionStorage`；阅读偏好只写入本机 `localStorage`，不写入海报、任务 ID、文字或回执。退出演示身份不删除本页临时任务，界面明确提示；删除任务仍使用工作台的原有操作。存储不可用时保留本页体验并说明无法保证刷新恢复。

结构影响：新增 `src/web/workspace.ts` 管理页面导航、演示身份与偏好；`app.ts` 仅向其投影实际任务状态；`host.ts` 提供动作设置入口；HTML/CSS 调整信息层级和响应式布局；服务端只新增该前端模块的静态资源映射。未修改领域契约、任务服务、模型适配器或导出规则，未增加依赖、数据库或对外部署。验证记录见 [页面与身份验证](product-navigation-20261022.md)。

## 2. 产品方案：用注意力推动一个可检查的小任务

一句话工作表述：**用一个可跳过的角色入口，引导人把公益海报整理成可阅读、可核对、可带走的文字版本。** 这是当前产品定义，尚未证实能降低核对负担。

- 直接操作者：有材料使用权的公益内容制作、转发或核对者；暂定角色，待研究验证。
- 接收者：需要大字阅读或依赖读屏获取信息的人；需要分别验证他们的使用环境与偏好。
- 第一件事：准确知道活动时间、地点、报名方式；缺信息时明确知道要向谁核实，而不是得到一个看似完整的编造答案。
- 产品叙事：角色争取注意力 → 科普解释障碍 → 操作者完成修订 → 导出可读版本 → 接收者使用 → 需求方确认是否采用。现在只实现到本地导出与操作者自报反馈。

与“人工转录 + 现有 OCR”相比，本项目要验证的增量是：关键字段不被遗漏、未知不被补写、全文可以修正、同版本检测与确认能追溯。若对照测试没有显示这些收益，就先简化流程；不以增加 Agent、模型或角色动作数量弥补证据不足。

角色不是受助者或真实服务人员，不代表残障群体发言。不要把“磕头”互动与受助者尊严绑定，也不把观众观看角色计为公益贡献。角色台词与视觉是否恰当仍需参与者反馈；保留直接进入任务的入口。

## 4. 价值判断与取舍

“有用”先看是否找对事实、是否知道哪些不能确定、是否减少修订遗漏；“有趣”单独看角色是否让人愿意理解问题且不妨碍任务；“社会价值”看结果是否被有需要的人实际使用。三者分开记录，不能相互抵销。

原 PRD 的 95% 关键事实正确率、80% 任务完成率是研究目标，当前没有可用于报告这些比例的真实样本。自动评估的保守字符串匹配也不等于语义正确率。先保存逐项错误、分母、样本来源和测试条件，再判断门槛。

无障碍的技术检查与真实参与者评估需要结合；少量参与者结果也不能推广到所有人。依据：[W3C：让用户参与无障碍评估](https://www.w3.org/WAI/test-evaluate/involving-users/)、[初步检查的覆盖边界](https://www.w3.org/WAI/test-evaluate/preliminary/)（2026-10-17 读取）。

下一阶段优先完成一次有限模型冒烟和一套授权真实材料的人工答案；模型/材料仍不可得时，保留这个缺口，不把合成评估升级为产品效果。

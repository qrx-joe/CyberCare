## 3. 已实现功能

### 3.1 首页与注意力入口（PRD 之外，10/16 方向纠偏后恢复）

- 品牌首页"求求你了，听我把话说完"，人类补丁 Logo，荧光黄 / 紫色视觉。
- 2D 概念角色：呼吸、自动眨眼、预设台词表情、低头动作。
  - 动作可关闭；减少动态或离屏时停止；动作结束复位。
  - 缺素材时先退到参考图，再退到文字角色。
- "先磕一个""随机互动"均为预设台词，页面标明"不是实时 AI 对话"。
- 3 条固定科普，带 W3C 等来源链接，可直接进入任务。
- "整理前后"只读对照：不上传即可看原图和整理结果。
  - 默认展示 Wikidata 海报的 AI 识别存档，标明 `step-5-preview` / `poster-extract-v4`、四项均为模型输出。
  - 可切回合成样例；查看不创建任务。

### 3.2 提交材料（FR-002）

- 三种处理方式：内置合成样例（离线、非 AI）、上传图片 + 人工转录、真实视觉识别（需配置 StepFun）。
- 服务端校验图片：PNG / JPEG / WebP；检查文件签名、扩展名和实际尺寸（单边 ≤ 8000 px，总像素 ≤ 1600 万）。伪装文件、超大图、损坏图均拒绝。
- 上传前提醒不要提交身份证、手机号、密码、验证码。
- 必须勾选"有权处理该材料"，并告知真实识别会把图片发给 StepFun。
- 幂等创建：响应丢失后用同一材料重试，复用原任务，不会重复付费调用。

### 3.3 识别与提取（FR-003）

- StepFun 视觉模型，提示词 `poster-extract-v6`。输出完整原文、概述、图像说明、四项字段和不确定项。
- 逐字引用约束：字段值必须出现在引文中，引文必须出现在全文中；对不上的标为"待核实"，不作为依据。
- 不补全年份、联系方式、报名地址；不解码、不访问二维码。
- 图中文字一律视为不可信资料，不执行其中指令；`<script>` 和"忽略规则"类文字只作为普通文本显示。
- 无可读文字的图片四项保留未知，并给出提示。
- 请求预算：进程最多 10 次（可下调）、每任务 1 次、无自动重试；超时默认 30 秒，最高 90 秒；鉴权 / 额度错误立即停用。
- 识别失败或取消后，可保留图片和来源，转人工转录。

### 3.4 人工核对与修订（FR-007 纠错部分、FR-010）

- 原图可放大、缩小、方向键移动；字段旁显示"提取依据"。
- 空白字段给出具体核实提示（例如"请向活动方询问报名入口和截止时间"）。
- 四项、完整正文、概述、图像说明均可修订；必须填写修改依据，保留修订记录。
- 时间核对：活动日期、报名截止、提交截止需人工选择和分类，不自动拼接；无年份时提醒核实，不自动补。
- 字段与正文对照：字段改了正文没改时提示，可保留差异但需说明。
- 概述来源可选"根据四项信息生成"或"人工核对概述"。

### 3.5 自动检测与确认门禁（FR-006、FR-010）

- 检测对象是本次将导出的完整 HTML，服务端在本机 Chrome / Edge 中实际运行 axe。
- axe 运行失败不记为"零问题"。
- 任何修改都会使旧检测和确认失效，须重新检测、重新确认。
- 四项逐项勾选（空白即确认保留未知），另需确认整体一致性。
- 未确认时 HTML 下载接口返回 409。

### 3.6 结果与导出（FR-006）

- 三类下载：纯文本；大字 HTML（离线可读，6 段标题目录）；证据 JSON（来源、修订、检测、HTML 哈希）。
- 复制文字；剪贴板被拒时自动选中文字，并提示键盘复制或下载。
- A+ 大字模式；200% 文字与 320 px 宽度下无横向滚动。
- 主流程可仅用键盘完成（自动化测试覆盖）。
- 状态和错误通过 `role=status` / `role=alert` 播报，不只依赖颜色。

### 3.7 反馈（FR-007）

- 三档自报反馈：有帮助 / 部分有帮助 / 没有帮助。
- 保存后标注"未经独立核实"，不作为效果证据。

### 3.8 隐私与生命周期（FR-008）

- 服务仅监听 `127.0.0.1`；原图只在内存，不写磁盘；任务 30 分钟过期（PRD 建议 ≤ 24 小时）。
- 会话归属：其他浏览器访问同一任务 ID 返回 404。
- 删除、取消、过期后，晚到的模型 / 检测 / 保存响应不能恢复任务。
- 状态读取中断可重新读取，不重新提交，也不延长过期时间。
- 页面不接触模型密钥；`.env` 不进 Git。

### 3.9 工程保障

- 运行版本核对：运行中的服务落后于磁盘构建时提醒，按内容哈希判断，不看时间戳。
- 可复跑的离线评估包；只读示例在构建时校验字段、来源链接、路径、图片哈希和体积。

## 4. 未实现与差距

1. 语音转写（FR-004）、截图操作指导（FR-005）：两条 P0 完全未做，首页也未提及。
2. 高风险识别（FR-009）：对付款、转账、医疗、法律类内容没有专门提示。
3. 反馈不完整（FR-007）：缺"内容存在错误"选项和文字补充；没有"让模型重新识别"，纠错只靠人工修订。
4. 上传上限低于 PRD：2 MB 对 10 MB。PRD 写明以实际能力为准，影响小。
5. M-08 简明版与朗读、M-10 工作台、M-11 人工支持均未做。
6. PRD 验证目标未达成：10 张真实海报、5 人用户测试、读屏软件实测都没有完成。

## 5. 路演表述建议

- 不说"实现了 PRD"。
- 建议说法：PRD 规划三条服务，MVP 集中做通其中价值最清楚的图片链路，做到可核对、可导出、不编造；语音和截图是下一阶段。
- 取舍依据可直接引用 [MVP 方案](mvp-plan-20261022.md) 第 2 节的冲突处理表。

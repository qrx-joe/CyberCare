# 参考风格前端改造

日期：2026-10-19，Asia/Shanghai。本轮由用户授权，基于 `preview (6).html` 的[设计评审](preview6-design-review-20261018.md)优化现有本地前端。参考原文件未改动。

## 实现

- 采用纸色、深墨色、荧光黄与紫色，统一粗线框、方形按钮、硬边阴影和无衬线大标题。首屏集中呈现主行动、科普入口、角色与预设互动。
- 保留“赛博公益”名称与现有本地角色。没有移入参考的新角色、三类服务或拟制服务数字。角色授权仍待核实，素材继续只在忽略目录保存；缺素材时仍有静态或文字退路。
- 海报区改为核对工作台：桌面显示流程侧栏、原件输入与核对结果；窄屏改为顶部进度与上下排列。进度由现有任务状态驱动，失败、取消和完成显示对应文字，不提供跳过核对的入口。
- 大字按钮移至全局页头，保留 125% 字号；320px 窄屏及 200% 文字放大时允许自然换行。手机容器留白设上限，避免随文字放大挤占阅读宽度。
- 结果自然撑开容器，显式保留 `[hidden]` 隐藏规则，防止空态继续占位挤出长结果。字段未知提示、全文修订、版本检测、逐项确认、导出和删除流程继续使用原有实现。

## 验证与限制

`npm.cmd test`：20/20 通过，包含构建与 TypeScript strict 编译。`npm.cmd run test:e2e`：19/19 通过，包含原有角色像素帧变化、关闭动作、减少动态、键盘流程、复制退路、过期与迟到响应、修改失效、导出同版本等检查。

新增浏览器用例用超过 5,000 字的原创合成材料实际生成草稿、检测、确认，再检查 1440/390/320px 与大字状态下结果位于面板内、页脚在结果之后、页面没有横向溢出；检查进度随提交、核对、完成和删除变化。窄屏叠加 200% 文字也检查横向溢出。本轮没有调用外部模型，不把合成流程测试作为真实识别效果。

首次浏览器回归为 17/19：顶部提示条位于地标外，触发两处 `region` 检查失败。修复方式是将提示条纳入页头，保留检查。进一步查看 axe 的不确定项后，为产物说明组增加适当语义，并给角色区文字设置实色底，避免纹理妨碍对比检查。最终整页自动检查没有报告违规；仍有 1 个 `color-contrast` 不确定项：科普按钮内仅含装饰箭头的元素。该符号为 `aria-hidden`，其前景 `#191b19`、底色 `#fffef9` 的对比度计算为 17.16:1；保留原始不确定项记录，不将其改记为自动通过。自动检查通过不代表 WCAG 符合性或真实用户可用性。

本地截图和报告位于 `.local/validation/reference-frontend-20261019/`，不进 Git：桌面与手机首屏、实际合成草稿工作台、320px 大字长结果、详细 axe 报告。页面流程和画面已本地核对；尚无目标用户测试、公益采用或社会效果证据。

## 结构影响与下一步

需求经过页面结构、样式与前端任务渲染三层。实际修改 `src/web/index.html`、`style.css`、`app.ts`，新增 `tests/browser/reference-layout.spec.mjs`。服务、领域规则、Provider、API 契约、依赖和导出模板未修改，因为本轮目标是视觉与布局优化；模式区分、会话归属和确认门禁继续由原链路负责。

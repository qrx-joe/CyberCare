# 方向纠偏：把“抽象入口”接回公益行动

日期：2026-10-16。依据：用户在海报 MVP 后指出“这个和我们那个抽象的方向不一致”，提供“赛博公益 / 求求你了，听我把话说完 / 不求打赏，只求一点注意力”的角色海报。它是视觉与产品方向参考，不是其中二维码、网址的操作授权。

后续状态：本文件保留首次纠偏的实现记录。用户随后要求数字人动态化，已将整幅参考图的短动作替换为独立角色的眨眼、表情与低头帧动画；当前实现、素材和验收以 [角色动画记录](avatar-motion-20261016.md) 为准。

## 纠偏结论

上一版验证了海报处理机制，但将研究里的角色、开场、科普与互动整体顺延，使产品首屏变成内容核对工具。技术收敛不应该把有记忆点的入口同时删掉。

本轮保留海报作为第一个小任务，恢复完整路径：

```text
角色让人停留 → 预设抽象互动 → 了解一个无障碍问题
  → 邀请用户做一件小事 → 海报草稿 / 修改 / 检测 / 确认
  → 角色反馈 + 可复查回执
```

这仍然是产品假设。没有证据证明角色能提升停留、任务转化或社会效果；不能从图的吸引力直接外推成绩。

## 本次最小实现

| 参考里的方向 | 实际实现 | 边界 |
|---|---|---|
| 霓虹、赛博、角色求注意力 | 深蓝 / 青色 / 淡紫首屏，使用用户提供图的角色区域作本地参考 | 原图未修改；没有重新生成角色或确认正式角色身份 |
| “求求你了，听我把话说完” | 首屏文案、角色对话框、明确的小任务入口 | 文案为本轮原型，未验证转化效果 |
| 抽象角色 / 先磕一个 | 手动触发的短暂 2D 画面动作、“咚”、预设反差台词 | 不是真实骨骼动画或 3D 虚拟人；动作结束复位，可重复，可关闭；减少动态时停用 |
| 随机互动 | 本地预设台词随机选择 | 非实时 AI 对话，无模型请求 |
| 每日科普 | 3 张有来源、可切换的短科普示例 | 明确标“固定示例 / 非每日更新服务”；不虚构内容更新能力 |
| 往期回看 | 本轮不建设历史内容库 | 当前任务仍可下载回执；不生成虚构往期、粉丝或公益次数 |
| 公益行动 | 引导到已实现的海报单链路；将样例、手工转录、真实模型分开标识 | 原检测、版本、逐项确认、导出、删除规则保持 |
| 做完之后的角色反馈 | “这次咱俩都站着。” + 本次核对完成说明 | 不说“已经帮助了一个人”；用户反馈与机构采用仍分开 |

科普依据：[W3C 图片教程](https://www.w3.org/WAI/tutorials/images/)说明图片需要按用途提供文字替代；[W3C 无障碍评估](https://www.w3.org/WAI/test-evaluate/)说明工具不能单独判定符合性，需要人的评估。科普内容采用简短转述，并直接连接到海报核对任务。

## 结构影响

- `src/web/host.ts`：新增浏览器内的角色台词、科普、入口跳转、2D 动作与减少动态逻辑。它不请求模型、不判断任务完成。
- `src/web/app.ts`：将现有任务状态传给角色；核心表单和服务规则保持。
- `index.html` / `style.css`：恢复产品叙事与视觉入口，任务区保留易读的核对界面。
- `server.ts` / `scripts/build.mjs`：仅添加新浏览器模块和可选本地图片的静态资源路径，并保证缺素材时明确返回 404；没有新业务 API、数据表或生产依赖。
- Provider、任务状态机、确认契约、受控导出模板未变；音频、截图、云 TTS、3D 模型、公开分享和外部发布继续顺延。

## 验收

1. 首页先展示“求注意力”的角色与互动；也能通过跳转链接直接进入海报转换，不强迫观看。
2. “先磕一个”每次触发短 2D 动作，结束后复位；关闭动作或减少动态设置下只有文字反馈。
3. 科普可展开、切换和进入真实任务；来源可回查，无每日更新或实时聊天暗示。
4. 从角色入口能走完原来的修改、axe、逐项确认和导出；回执与角色反馈不夸大效果。
5. 参考图缺失仍能完成任务；320 / 390 / 1440px、200% 字号与新入口的 axe 定向检查有实际记录。

本轮实际结果追加到 [验证记录](validation-20261016.md)。下一阶段仍优先补“一张有权处理的真实海报 + 人工答案 + 有上限的真实模型测试”，同时用经同意的参与者观察“角色→科普→任务”是否能被理解，不先扩成泛聊天或内容平台。

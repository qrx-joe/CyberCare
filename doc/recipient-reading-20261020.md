# 接收者大字页面：可定位的阅读结构

日期：2026-10-20（Asia/Shanghai）。本节点完善本地导出的接收者页面，不增加模型、云端发布或用户效果声明。

## 问题与结果

旧 HTML 只有“海报文字版”和“完整文字与来源”两个标题；概述、图像说明、全文和来源都混在一个 `pre` 中，而且额外嵌入整份纯文本报告，重复列出活动字段。新增浏览器回归先在旧模板失败，实际标题列表证实这一结构。

现在有活动信息、内容概述、图像说明、完整文字、提取时的不确定项、来源与处理说明六个内容标题，以及原生页内阅读目录。六个链接均可用键盘跳转并将焦点移到对应标题；没有运行时脚本或联网资源。HTML 不再嵌入整份纯文本报告，正文里的原始活动文字照常保留。打印隐藏目录，保留活动信息与完整文字。

采用标题和页内导航的依据是 [W3C WAI 标题教程](https://www.w3.org/WAI/tutorials/page-structure/headings/)：标题表达内容组织，并可供浏览器与辅助技术定位。此处只落实结构，不把自动化验证当成实际读屏体验或完整 WCAG 符合性。

## 保留的约束

未知报名方式仍明确显示为未知；缺年份及相对日期提示放在活动信息后。概述、说明和完整文字使用当前修订版；初次提取的不确定项单独保留并说明其历史性质。来源、正文和字段继续转义为纯文本，不自动激活来源中的网址、图片或代码。

检测与导出继续使用同一个 `renderHtml`，不按确认状态改变模板。实际下载文件 SHA-256 与回执检测哈希一致，本次合成回归为 `8b9b649daefe0954c8217df0b6a3036df37148712370b75809f673e89f736b57`。纯文本与证据 JSON 格式未改变。

# 识别失败后的人工转录退路

日期：2026-10-19，Asia/Shanghai。功能提交：`8913634`。承接[首张公开海报超时](public-material-20261019.md)，本节点解决失败后继续完成任务的问题，不改变模型提取能力。

## 行为

此前，真实识别失败或取消后只能删除任务再开始；删除会清空本页选图与来源。现增加“保留图片，改用人工转录”：

- 仅在真实识别任务失败或取消后显示，点击前说明会删除本次任务。
- 删除旧服务端任务后，保留本页选图、预览和来源，切到人工转录并聚焦文字输入；材料声明重新勾选。
- 本页保留材料沿用原有最早到期时间。到期、手动删除或迟到响应仍走清空规则；转人工本身不重新计算本页期限。
- 操作者粘贴转录后创建新的人工任务。新任务继续遵守既有服务端 30 分钟规则；本页较早的清空期限仍有效。页面清空不声称同时撤回已发送的第三方请求或已经下载的文件。
- 人工草稿继续经过修改、实际 axe 检测、逐项确认及导出，界面标注“非 OCR / AI”。切换和人工路径均不调用模型。

这提供同一页面内的退路，刷新或关闭页面后的材料恢复仍未实现；不能把它称作持久化任务历史。

## 验证

先加入回归再修改：失败状态已出现，但 `#manual-fallback` 不存在，定向浏览器检查失败。修复后：

| 检查 | 实际结果 |
|---|---|
| `npm.cmd test` | TypeScript strict 构建及 25/25 业务检查通过 |
| `npm.cmd run test:e2e` | 24/24 通过，0 跳过、0 意外失败、0 flaky，约 68 秒 |
| 新增：失败后人工完成 | 保留同一图片字节与来源、旧任务实际删除、材料声明重置；实际人工创建、axe、确认与纯文本下载通过 |
| 新增：取消后原期限 | 转人工前推进 15 分钟，再推进 16 分钟；本页图片、来源和未提交文字均清空；320px 大字布局无横向溢出 |
| 新增：删除响应晚到 | 切换期间到期，迟到响应不能恢复图片、来源或任务控件 |

失败和取消状态由浏览器测试明确模拟；测试向实际服务端提交的是原创合成人工转录，未向 StepFun 发送请求。模型可用选项也是测试替代，不作为真实连通证据。后续的删除、人工生成、检测、确认及下载使用实际本地服务。本轮外部模型请求 **0 次**，不能将三项浏览器回归计入真实模型样本。

已查看 390px 失败提示与 320px 大字人工输入截图，文字及按钮可读。修复前后报告和截图保存在 `.local/validation/manual-fallback-20261019/`，不进 Git。自动检查与代理画面核对不替代目标用户使用或真人读屏测试。

Provider 的模拟请求验证了硬请求上限、无自动重试和鉴权失败后停止，并读取了模拟 usage。这些是假响应，不是实际消耗或模型质量评估。真实上游失败、延迟和超时尚未现场验证。

5 条浏览器场景：

1. 合成样例 → 修改字段 → 服务端真实 axe → 四字段及完整内容确认 → 导出 → 自报反馈 → 删除；下载 HTML 的 SHA-256 与该版本检测记录一致。跨会话访问返回 404。大字模式下最终文字实际放大。
2. 人工转录含 `<script>` 和诱导指令文字安全显示；未确认禁止导出；跨来源写请求拒绝；页面 axe 与 1440 / 390 / 320 CSS px 无整页水平溢出。
3. 开发者原创 SVG 在浏览器渲染为 PNG 后上传，服务端实际解码成功；非图片伪装、9000px 图片、错误扩展名和截断图片被拒绝。此 PNG 是合成测试素材，不是真实公益海报。
4. 第一次创建响应丢失后，相同材料再提交沿用同一个幂等键，服务端复用原任务 ID，不创建第二个任务。
5. 主要流程仅通过 Tab / Enter / Space / 方向键完成：提交、检测、逐项确认、下载、自报反馈、删除。320px 宽度和根字号 200% 时无整页横向溢出，最终文字计算字号至少 32px。此项是浏览器键盘自动化，不是目标用户 / 读屏测试。

# 页面拆分与演示身份

日期：2026-10-22。范围为本地原型的产品组织与交互完善。

## 完成标准

- 首页、海报工作台、我的工作台各自有明确入口、标题和当前导航状态；浏览器前进后退可用。
- 切换视图、登录和退出演示身份不提交材料、不修改任务、不清除尚未保存的字段、不绕过检测及逐项确认。
- 演示身份明确标注为模拟，游客不受限；身份与阅读偏好可在允许存储时恢复，刷新不恢复任务。
- 当前任务入口反映实际状态；删除与到期后清空，不显示虚构历史、公益积分或影响数字。
- 键盘焦点留在登录弹窗内；关闭后返回触发按钮。支持 Esc、游客继续和点击遮罩关闭。
- 在 1440、390、320 像素视口和 200% 字号下检查布局；记录 axe violations 与 incomplete，不将自动化结果视为完整无障碍合规。

## 实现边界

浏览器片段导航是同一应用的三个视图，未引入多份页面和框架路由。演示身份不属于服务端授权机制，切换身份不会改变已有会话 Cookie，也不会恢复、转移或删除任务。关闭标签页结束普通标签页会话；浏览器的恢复标签页行为由浏览器决定，不能把 `sessionStorage` 描述为安全身份保管机制。

阅读偏好包括大字模式和关闭角色动作，系统减少动态设置优先。只持久化预设身份枚举和偏好布尔值，任务及材料仍遵循既有内存生命周期。真实识别、人工转录和合成示例的来源说明保持分开。

本轮前已有角色动作与构建修改，继续保留。新增生产代码集中在 `src/web/workspace.ts`、`src/web/index.html`、`src/web/style.css`；原业务 UI 通过 `app.ts` 投影任务状态，`host.ts` 增加动作设置并交由导航处理工作台入口，`server.ts` 增加一个静态 JS 资源。现有业务浏览器用例改为进入 `/#workbench`，混合场景显式通过导航来回切换。
